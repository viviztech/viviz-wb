Official setup

  1. 1

    Accept Meta's product terms

    Open App Dashboard > WhatsApp > Quickstart. In “Improve ROI with marketing messages with optimizations,” select Get started, continue to the integration guide, and accept the Terms of Service.

  2. 2

    Subscribe the messages webhook

    Delivery events use the normal messages webhook field. The button below subscribes this app at WABA level.

  3. 3

    Send an approved MARKETING template

    Marketing broadcasts in this app automatically use /marketing_messages. Utility templates continue to use the standard messages endpoint.

  4. 4

    Verify the status webhook

    The app marks routing verified when Meta returns pricing.category or conversation.origin.type as marketing_lite.

How this app uses it

Meta's Marketing Messages API is a send endpoint for approved marketing templates. Meta automatically routes eligible messages and reports the result through standard message-status webhooks.

Only contacts with active marketing consent are eligible.

Frequency caps, STOP handling, template approval and quality checks remain enforced.

The same approved templates, credentials and phone number are used.

No token is placed in a URL or browser-visible request.

Important: API connectivity does not prove product eligibility. Meta confirms optimized routing only on a real message status webhook.
